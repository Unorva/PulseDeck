# PulseDeck 0.4.3 · Windows

- 删除“环状流场”场景，保留信号流场、聚变、三体和推理四个场景。设置、主界面标签、托盘菜单和 1–4 快捷键保持一致。
- 原“黑洞引擎”改为“信号流场”，移除可见黑洞及隐藏的单点引力汇聚。粒子从圆环较宽的区域连续发射，再按对应指标分流进入卡片。
- 三体黑洞改用明暗不均的暖色新月光晕、暗色中心和细窄光子环；保留范围约束和相互引力，不恢复星环或轨迹装饰。缓存光晕图像，避免每帧重复绘制模糊效果。
- 移除画布左上角的英文 NEURAL OBSERVATORY 与“环状运算中枢”标题，开启仪表标注也不会再次显示。
- 已保存的旧环状流场与黑洞配置自动迁移到信号流场，保留配色、粒子数量和速度等设置。

安装版：`release/PulseDeck-Setup-0.4.3-x64.exe`。

免安装版：`release/PulseDeck-Portable-0.4.3-x64.exe`。

验证：35 项逻辑测试与 4 项静态构建测试通过。浏览器检查四场景与快捷键、旧设置迁移、仅三体绘制黑洞、左上角标题移除及两种绘制方式。运行截图与记录保存在本机 `artifacts/qa-0.4.3/`，不纳入源码提交。

打包程序检查通过：设置中仅显示四个场景，信号流场不绘制黑洞，切回三体后恢复三颗黑洞；200% 缩放的 3200×2000 主屏与 100% 缩放的 1920×1080 副屏均保持全屏覆盖和持续绘制，五张指标卡与六张监测卡完整。
