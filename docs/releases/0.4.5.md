# PulseDeck 0.4.5 · Windows

- 星链球的自动随机转动与点亮改为每 10 次有效新采样触发一次，重复样本不计数，暂停时不积压触发事件。
- 圆环流出效果改为可辨认的发光粒子与极短光尾，移除连续的光线/光带。发射源连续游移，粒子从更细分的位置流出，源区域上下两侧的密度与亮度平滑淡出。
- CPU、内存、GPU、下载和上传采用独立速度范围，各自随对应数值变化，颜色继续与右侧卡片色标一致。
- 三体按新参考图收紧中央黑洞簇；保留相互引力与运动范围限制，多股粒子流在黑洞附近汇聚、偏转，再进入指标卡。圆环增加局部计算亮带。
- “推理引擎”调整为“矩阵计算”：六个标注层级、交叉矩阵连接和沿实际节点路线行进的粒子，最后输出至五张卡片。
- 粒子抵达卡片时点亮同色接收点与边框，流量较强时更明显；没有抵达事件时自然衰减。

安装版：`release/PulseDeck-Setup-0.4.5-x64.exe`。

免安装版：`release/PulseDeck-Portable-0.4.5-x64.exe`。

验证：44 项逻辑测试与 4 项静态构建测试通过。运行检查确认第十次采样触发、短尾粒子长度、五项颜色匹配、卡片到达光效，以及矩阵和三体场景正常显示。圆环亮点合并绘制，减少逐点光晕的绘制开销。最终打包程序通过 3200×2000（200% 缩放）与 1920×1080（100% 缩放）两块屏幕的实际边界、可见性和动画检查，并确认矩阵六层标注正常、信号流场不含黑洞。截图与记录保存在本机 `artifacts/qa-0.4.5/`。
