# PulseDeck 0.4.2 · Windows

- 三颗黑洞保留相互引力，并限定在中央椭圆区域内。靠近边界时逐渐回到场内；拖动到范围外或高速释放也不会飞出画面。
- 黑洞显示暗色事件视界与柔和光晕，移除倾斜星环和轨迹装饰。
- 粒子从左侧圆环连续流出，受共享引力和路径引导影响，经过黑洞附近后分成五组进入对应指标卡。CPU 控制本组流速，内存控制密度，GPU 与网络收发分别控制本组流速及密度。移除独立的卡片连接线，所有分流路径均由运动粒子呈现。
- 壁纸使用显示器的实际像素范围，补偿 Chromium 隐藏边框，并在显示后重新校准绘制区域。页面移除边缘留白和最大宽度限制，铺满所选显示器。
- 修正依赖锁定文件的版本元数据，保留原有第三方依赖版本与校验值。

安装版：`release/PulseDeck-Setup-0.4.2-x64.exe`。

免安装版：`release/PulseDeck-Portable-0.4.2-x64.exe`。

34 项逻辑测试和 4 项静态构建测试通过，包括长时间边界约束、极端拖动后释放、粒子经过黑洞后进入对应卡片，以及各组流速独立变化。浏览器检查覆盖五种模式、WebGL 与 Canvas 2D。

双屏覆盖检查核对实际绘制区域：200% 缩放的 3200×2000 主屏，和位于 x=3200 的 100% 缩放 1920×1080 副屏。两个屏幕的客户区像素边界与显示器完全一致，页面无外围留白，右侧五项读数及底部六卡完整。
