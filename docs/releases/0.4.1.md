# PulseDeck 0.4.1 · Windows

- 壁纸嵌入桌面后通过 Electron 同步显示窗口并请求重绘；载入超时或渲染进程退出时恢复设置入口，避免保留无响应的黑色壁纸窗口。
- 图形加速初始化失败或上下文丢失时使用 Canvas 2D；上下文恢复后重新初始化加速绘制。
- 五组粒子与右侧五张卡片共用颜色和连接线。CPU 负载驱动流速，内存占用驱动密度，GPU、下载和上传分别驱动各自粒子的流速与密度。悬停或聚焦卡片可突出对应粒子。
- 网络速率按固定的 0–100 MiB/s 对数尺度映射，保留低速时的可见变化；缺失数据明确显示待机状态，未使用模拟遥测。
- 移除左侧神经球中央的英文、编号与不透明底板，展示完整的神经网络。

Windows 安装版：`release/PulseDeck-Setup-0.4.1-x64.exe`。

免安装版：`release/PulseDeck-Portable-0.4.1-x64.exe`。

验证：30 项逻辑测试与 4 项静态构建测试通过；浏览器中检查了五模式、卡片高亮、Canvas 2D 回退和 WebGL 丢失/恢复。打包后的程序在 1600×1000 与 1920×1080 两台显示器分别完成壁纸应用、持续绘制与停止检查，未出现页面错误。检查截图与记录保存在本机 `artifacts/qa-0.4.1/`，不包含在源码提交中。
