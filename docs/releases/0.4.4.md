# PulseDeck 0.4.4 · Windows

- 黑洞按用户参考图恢复为清晰黑色中心与完整圆形柔光晕，增强亮度和扩散范围；光晕随所选主题色及高光色绘制，切换主题时平滑过渡，移除新月亮边与独立环线。
- 星链球随每次新采样轻微随机改变三轴旋转方向，并自动点亮局部节点、传播光脉冲。重复采样不重复触发；暂停时不积压发光事件，鼠标交互仍可使用。
- 移除圆环出口的硬光栅和堆叠亮弧，改为沿实际粒子路线持续行进的柔光尾迹；亮迹向外逐渐变宽、扩散、淡出。
- 粒子先沿圆环局部法线向外喷出一段约为圆环半径 22% 的距离，再逐渐扩散、受引力偏转并进入对应指标卡。
- 粒子、出口柔光和对应右侧指标卡的色标使用同一颜色来源，五项指标在每套主题下保持对应关系。
- 包含 0.4.3 的场景精简、无黑洞信号流场、新三体光晕、旧配置迁移和左上角标题移除；保留已验证的双屏全屏覆盖及指标卡片。

安装版：`release/PulseDeck-Setup-0.4.4-x64.exe`。

免安装版：`release/PulseDeck-Portable-0.4.4-x64.exe`。

验证：40 项逻辑测试与 4 项静态构建测试通过，包括无需指针的采样响应、重复采样去重、发光传播与衰减、暂停行为及法线喷流方向。截图及运行记录保存在本机 `artifacts/qa-0.4.4/`，不纳入源码提交。

四套主题均完成实际像素检查：黑洞光晕随主题变化，粒子及出口柔光的实际绘制颜色与对应卡片色标一致。无鼠标点击时已观察到连续采样引发节点发光。最终打包程序在 200% 缩放的 3200×2000 主屏和 100% 缩放的 1920×1080 副屏均完成全屏覆盖、持续绘制及场景切换检查。
