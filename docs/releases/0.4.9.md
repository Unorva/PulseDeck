# PulseDeck v0.4.9 · 首个公开版本

发布日期：2026-11-13。此前的 0.4.x 为开发迭代，本次沿用应用实际版本号 0.4.9。

## 本次发布

- Windows 10 / 11 x64 动态桌面壁纸，动画位于桌面图标之后，搭配独立设置窗口、普通展示窗口和托盘菜单。
- 信号流场、聚变引擎、三体引擎、矩阵计算四种视觉模式，冷白银、香槟金、深海蓝、星云紫四套配色。
- CPU、物理内存、GPU、下载、上传实时读数，以及六张监测卡片与进程榜。数据不可用时明确显示 N/A。
- 五组指标粒子独立响应对应硬件数据，颜色与右侧卡片一致，抵达时点亮接收点和边框。
- 神经球体每五次有效新采样平滑随机转动并传播节点光脉冲；三体模式包含有边界的相互引力与粒子偏转；矩阵模式包含六层节点传递。
- 0.4.9 的圆环数据条覆盖完整环带宽度，从内缘连续穿过环面并进入外侧柔和扩散，保留游移、两侧淡出的出口与独立指标颜色、速度。
- 支持目标显示器选择、混合缩放、粒子与光效调节、帧率上限、全屏 / 电池暂停及可选开机启动。

## 下载

在本 Release 的 Assets 中选择一个文件：

- `PulseDeck-Setup-0.4.9-x64.exe`：安装版，可选择目录并创建快捷方式。
- `PulseDeck-Portable-0.4.9-x64.exe`：免安装版，下载后直接运行。
- `SHA256SUMS.txt`：以上两个文件的 SHA-256 校验值。

无需安装 Node.js。启动后选择引擎与显示器，点击“应用到桌面”。关闭设置窗口会保留托盘运行，通过托盘菜单或“退出软件”完全退出。

## 已知限制

- 当前文件未进行 Windows 代码签名，首次运行可能出现 SmartScreen 提示；请确认下载来源并核对校验值。
- GPU 利用率、温度和显存可用性受硬件与驱动影响，不支持时显示 N/A；网络采样在启动时可能短暂预热。
- 壁纸嵌入依赖 Windows Explorer 桌面层，桌面层断开时可停止后重新应用。
- 当前一次选择一块显示器；本次不提供 macOS、Linux 或 ARM64 原生包。
- 三体为艺术化的牛顿引力视觉模拟，不是相对论模型。高粒子数和高帧率会增加资源占用。
