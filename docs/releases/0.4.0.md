# PulseDeck 0.4.0 · Windows

PulseDeck 现在是带独立设置窗口、托盘和动态桌面壁纸的 Windows 软件。

- 三颗小黑洞互相施加引力，并共同牵引、偏转和捕获粒子；拖动一颗会改变另外两颗的运动和流场。
- 加宽计算圆环，细密光栅与粒子沿环面法线输出，圆环内部支持信号传播与鼠标交互。
- 桌面保留原来的右侧五项读数与底部六张监测卡片，设置集中在独立窗口。
- 五种视觉模式、四套配色、帧率上限、显示器选择、全屏/电池暂停与可选开机启动。
- CPU、内存、GPU 和网络来自本机只读采样，不可用的驱动指标显示 N/A。

选择 **Portable** 免安装直接运行，或使用 **Setup** 安装版。无需安装 Node.js。

构建未使用商业代码签名证书。动态壁纸依赖 Windows Explorer 的桌面层，应用关闭或停止壁纸后恢复原有桌面背景。
